# 6. ML-модель прогноза PM2.5 (инструмент Forecast Agent)

Обучение: [`scripts/train_forecast_model.py`](../scripts/train_forecast_model.py),
паспорт модели: [`models/model_card.json`](../models/model_card.json).

## Данные

- 8 городов: Алматы, Астана, Шымкент, Караганда, Усть-Каменогорск, Павлодар, Актобе, Атырау.
- Период: 2023-01-01 … 2026-09-29, почасовые данные агрегированы в среднесуточные.
- PM2.5 — Open-Meteo Air Quality API (модель CAMS). Погода — Open-Meteo Archive API (реанализ ERA5).
- День засчитывается, если в нём есть хотя бы 18 часов наблюдений.

## Постановка

Базовый день `d0` — последний полный день наблюдений (вчера). Нужно предсказать среднесуточный PM2.5
в день `d0 + h`, где `h = 1…4` (сегодня, завтра, послезавтра, через 3 дня). Одна модель на все горизонты,
горизонт передаётся как признак. Целевая переменная — `log1p(PM2.5)`: распределение сильно скошено
из-за зимних пиков.

## Признаки (18)

| Группа | Признаки |
|---|---|
| История загрязнения | PM2.5 в `d0`, в `d0-1`, среднее за 7 дней, максимум в `d0` |
| Погода целевого дня | температура, влажность, ветер, давление, осадки, высота пограничного слоя (среднее и минимум) |
| Изменение погоды | изменение температуры и давления от `d0` к целевому дню |
| Календарь | месяц (sin и cos), день недели, отопительный сезон (15.10–15.04) |
| Горизонт | `h` |

Высота пограничного слоя — ключевой физический признак: когда слой низкий (инверсия),
выбросы остаются у земли.

## Валидация (без утечки будущего)

| Выборка | Период целевых дат | Назначение |
|---|---|---|
| train | до 2025-03-31 | обучение |
| calib | 2025-04-01 … 2025-09-30 | подбор ширины 80%-интервала |
| test | 2025-10-01 … 2026-09-29 (включая зиму 2025/26) | итоговая оценка |

Базовый прогноз (baseline) — «как вчера» (persistence): PM2.5 целевого дня = PM2.5 в `d0`.

## Результаты на тесте (MAE, мкг/м³)

| Горизонт | Модель | Baseline | Улучшение | Зима: модель | Зима: baseline | Покрытие 80%-интервала |
|---|---:|---:|---:|---:|---:|---:|
| 1 (сегодня) | 3.25 | 3.63 | 10% | 3.51 | 4.52 | 76% |
| 2 (завтра) | 3.51 | 4.64 | 24% | 3.75 | 5.80 | 76% |
| 3 | 3.56 | 4.94 | 28% | 3.82 | 6.34 | 75% |
| 4 | 3.60 | 5.11 | 30% | 3.87 | 6.69 | 76% |

Выводы:

- Модель лучше baseline на всех горизонтах. Выигрыш растёт с горизонтом и сильнее всего
  проявляется зимой (до 42% при h=4), то есть именно тогда, когда прогноз важнее всего.
- Фактическое покрытие интервала (75–76%) немного ниже номинальных 80%: интервал откалиброван
  на весенне-летних данных, а зимой ошибки больше. Улучшение для Ассайнмента 4 — калибровать
  интервал отдельно по сезонам.
- После оценки финальная модель переобучена на всех данных (37 776 строк). Метрики выше получены
  на модели, которая тестовый период не видела.

## Ограничения

- Целевая переменная — оценка CAMS, а не измерения станций.
- При обучении погода целевого дня «идеальная» (реанализ), а при использовании это прогноз погоды.
  Реальная ошибка будет несколько выше табличной.
